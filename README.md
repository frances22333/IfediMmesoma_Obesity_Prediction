
# IfediMmesoma Obesity Prediction

An educational machine learning application that predicts obesity categories using:

- Age
- Height
- Weight

## Prediction categories
- Underweight
- Normal
- Overweight
- Obese

## Model
Random Forest Classifier

## Technologies
- Python
- Scikit-learn
- Pandas
- Streamlit

## How to run
Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py

Note: This application is for educational purposes and is not a medical diagnostic tool.
